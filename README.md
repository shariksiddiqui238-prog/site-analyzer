# Site Analyzer

## Overview
A web application that analyzes website metadata such as HTTP status, response time, title, meta description, H1 count, word count, and image alt attributes.

## Setup
- Install dependencies
- Run the project
- Open in browser

## API
POST /analyze

## Design Decisions
- Auto-add https:// if missing.
- Added request timeout.
- Simple dashboard for better readability.

## Future Improvement
Refactor components and add more automated tests.
